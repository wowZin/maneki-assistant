# 数据源说明

## 同花顺 (ths) — 实时数据

通过同花顺实时行情 API 获取（Cookie 直连）。

**用途：**
- 实时行情（涨幅、涨速、量比、成交额）
- 主力资金净流入（f62 字段）
- 分时盘口数据
- 竞价数据

**访问方式：** Cookie 直连，无需代理。

## Tushare — 非实时/历史数据

通过 `http://api.tushare.pro` API 获取。

**用途：**
- 财务数据（ROE、净利润增长）
- 历史日线
- 涨停板列表（`limit_list_d`）
- 交易日历（`trade_cal`）
- 股票基本信息（`stock_basic`）

**限制：** 调用频率 `limit_list_d` 每天 10000 次。

## 数据优先级

```
同花顺Cookie直连(实时) > Tushare T+1兜底 > 纯CDP(向后兼容)
```

## Cookie 直连机制

使用同花顺 Cookie 直连，无需代理。

```python
# Cookie 直连，无需代理
resp = requests.get(url, timeout=5)
```

**可靠性策略：** Cookie 失效时刷新 Cookie 重试。
