# 五维度评分体系

Maneki 系统使用五个独立维度对股票进行评分，每个维度 0-100 分。

## 五个维度

| 维度 | 评分范围 | 数据源 | 说明 |
|------|---------|--------|------|
| [[基本面]] | 0-100 | Tushare (财务数据) | ROE、净利润增长、公告、股东变化 |
| [[技术面]] | 0-100 | Eastmoney (实时行情) | 换手率、均线形态、MACD、分时走势 |
| [[资金面]] | 0-100 | Eastmoney + Tushare | 主力净流入、龙虎榜、盘口、融资 |
| [[情绪面]] | 0-100 | Eastmoney (竞价/封板) | 连板基因、竞价热度、封板质量 |
| [[短线博弈]] | 0-100 | Eastmoney (实时) | 封单强度、攻击独特性、开盘博弈 |

## 总分计算 (2026-07-02 重构后)

**唯一总分 `total_score`**，由 sentiment 维度三个组件加权而成：

```
total_score = 0.4 * sentiment_amount_boosted
            + 0.5 * sentiment_position_combo
            + 0.7 * sentiment_volatility_combo
```

三个组件权重（0.4 / 0.5 / 0.7）为初始值，待通过训练集在 `backtest/optimize.py` 上重新搜索。

历史方案全部废弃，不作为参考。

维度打分仍保留 5 个（作为观察指标与 `sentiment_*_combo` 组件的输入），但不再以"加权 Top3"聚合成总分。

### 维度权重（供监控与旧 review 兼容，不参与 total_score）

| 维度 | .env 键 | 默认值 |
|------|---------|:----:|
| 基本面 | AGENT_WEIGHT_FUNDAMENTAL | 0.5 |
| 技术面 | AGENT_WEIGHT_TECHNICAL | 0.5 |
| 资金面 | AGENT_WEIGHT_FUND_FLOW | 1.5 |
| 情绪面 | AGENT_WEIGHT_SENTIMENT | 1.0 |
| 短线博弈 | AGENT_WEIGHT_SHORTTERM | 0.5 |
