# 短线博弈评分 — 打板专用

## 策略定位

专注A股涨停板打板博弈。五因子加权评分，针对两个核心问题：今天能不能封住（封板质量+板块助攻），明天有没有溢价（连板动量+攻击独特性）。

数据源：Tushare limit_list_d/stk_auction/daily/concept_detail/limit_cpt_list + 东财实时行情（集合竞价、换手率、量比）。

## 五因子权重

| 因子 | 权重 | 核心逻辑 |
|------|:--:|------|
| 封板质量 | 25% | 封板时间、封单流通比、撤单强度 |
| 连板动量 | 25% | 连板数、涨停基因、断板反包、涨幅活跃度 |
| 开盘博弈 | 15% | 开盘形态、换手率、量比 |
| 板块助攻 | 15% | 概念精确匹配+别名映射、板块涨停数、自身地位 |
| 攻击独特性 | 20% | 涨停高开率(>2%)、近10日最大涨幅、弱转强 |

集合竞价作为额外加分（最高+4.5分，权重0.3）。

## 逐因子评分规则

### 1. 封板质量（25%×100分→截断至100）

**封板时间**：

| 时间 | 分值 |
|------|:--:|
| 9:30前（停牌/秒板） | +50 |
| 9:30-10:00 | +40 |
| 10:00-10:30 | +25 |
| 10:30-11:30 | +20 |
| 13:00后 | +10 |

**封单流通比**（封单金额/流通市值）：

| 比例 | 分值 |
|------|:--:|
| > 15% | +50 |
| > 10% | +35 |
| > 5% | +25 |
| > 2% | +15 |
| > 0% | +10 |

**撤单强度**（终封/首封）：

| 比例 | 分值 |
|------|:--:|
| < 0.3 | -20 |
| < 0.6 | -10 |

今日未涨停：参考历史涨停记录 +10 分，无记录 0 分。

### 2. 连板动量（25%×100分→截断至100）

**连板数**（当前在连板中）：

| 连板数 | 分值 |
|------|:--:|
| ≥4连板 | +50 |
| 3连板 | +40 |
| 2连板 | +30 |
| 首板 | +15 |
| 断板(历史≥1连板) | +5 |

**涨停基因**（近30天涨停次数）：

| 次数 | 分值 |
|------|:--:|
| ≥5次 | +20 |
| ≥3次 | +10 |

**断板反包**：涨停日间隔2-9日（排除连续涨停）再次涨停 → +15

**涨幅活跃度**（近5日日均涨幅）：

| 涨幅 | 分值 |
|------|:--:|
| > 3% | +15 |
| > 1% | +5 |

### 3. 开盘博弈（15%×100分→截断至100）

**开盘形态**（相对昨收）：

| 跳空 | 分值 |
|------|:--:|
| ≥ 9.5%（一字/秒板）| +40 |
| ≥ 5% | +30 |
| ≥ 3% | +20 |
| ≥ 0% | +5 |
| < 0% | -10 |

**分歧转一致**：开盘<3%但最高触及涨停 → +20

**换手率**：

| 范围 | 分值 |
|------|:--:|
| 10%-30% | +25 |
| 30%-50% | +15 |
| > 50% | -5 |
| 5%-10% | +10 |
| 0%-5% | +5 |

**量比**：

| 范围 | 分值 |
|------|:--:|
| > 3 | +15 |
| > 2 | +10 |
| > 1.5 | +5 |

东财实时换手和量比可作为兜底数据。

### 4. 板块助攻（15%×100分→截断至100）

**概念匹配**：精确匹配 + 别名映射（如"芯片"↔"半导体"↔"集成电路"），避免短串误匹配。

**板块涨停数**（所属概念中最大值）：

| 涨停数 | 分值 |
|------|:--:|
| ≥ 20只 | +60 |
| ≥ 10只 | +50 |
| ≥ 5只 | +35 |
| ≥ 3只 | +25 |
| ≥ 1只 | +15 |
| 0只 | +5 |

**自身地位**：
- 自身在今日涨停池且所属概念有涨停 → +15
- 板块涨停≥5且自身涨停 → 板块前排 +20

### 5. 攻击独特性（20%×100分→截断至100）

**涨停次日高开率**（近20日有过涨停的次日，高开>2%的天数占比）：

| 比例 | 分值 |
|------|:--:|
| > 50% | +40 |

**近10日最大涨幅**：

| 涨幅 | 分值 |
|------|:--:|
| > 7% | +35 |

**弱转强**（昨涨停 + 今开[-2%,2%] + 今涨幅>4%）：

| 条件 | 分值 |
|------|:--:|
| 满足 | +25 |

### 集合竞价加分（0-15分，权重0.3）

| 条件 | 分值 |
|------|:--:|
| 量比>3 且 开盘3%-8% | +15 |
| 量比>2 且 开盘2%-8% | +10 |
| 量比>1.5 或 开盘2%-9.5% | +5 |
| 换手率>2% | +5 |
