# 情绪面评分

> **2026-07-02 重构后**：`total_score` 的三个组件（`sentiment_amount_boosted / sentiment_position_combo / sentiment_volatility_combo`）全部来自本维度，见 [`factors.md`](./factors.md#维度sentiment)。



## 策略定位

专注A股T+1~T+3情绪周期博弈。五维度量化评分，含一票否决规则（核按钮检测、情绪熔断）、高位情绪折扣。

数据源：Tushare limit_list_d/limit_step/limit_cpt_list/stk_auction + 同花顺实时行情 + 同花顺人气排名。

## 五维度权重

| 维度 | 权重 | 核心逻辑 |
|------|:--:|------|
| 大盘整体情绪 | 30分 | 赚钱效应、涨跌结构、炸板控制、空间高度 |
| 主线题材情绪 | 30分 | 题材地位、发酵强度、资金共识、周期标签 |
| 板块梯队情绪 | 20分 | 板块涨停数、连板梯队 |
| 个股人气资金 | 10分 | 换手活跃度、资金记忆、龙虎榜偏好、连板基因 |
| 集合竞价动能 | 15分 | 开盘跳空×市场乘数、竞价量比、竞价成交额 |

## 评估时间策略

- 尾盘决策（14:30后）：全部否决规则激活

## 一票否决规则

触发任一直接返回 0 分：

### 否决1：市场退潮
炸板率 > 45% 或 涨停家数 < 15

### 否决6：情绪退潮熔断
炸板率 > 40% 且 跌停家数 > 15 → 禁止新开仓
当最高连板 ≤ 2 板时，标注"冰点拐点"（市场可能触及冰点后修复，但仍禁止开仓）

### 否决2：主线崩塌
所属概念涨停数 = 0

### 否决3：高位杀跌
市场最高连板 < 2

### 否决4：个股情绪溃散（核按钮）

**A. 诱多核按钮**：
- 当日最高价较前收盘价涨幅曾>3%但收盘跌停（已修复，比较前收盘价）
- 换手率 > 近10日均换手率1.5倍
- 近5日内出现≥1次

**B. 一字闷杀**：
- 开盘即跌停且全天未开板
- 需满足 d_high >= d_close * 0.99（一字闷杀修复检测）
- 无需换手率确认
- 近5日内出现≥1次

**豁免**：曾出现过涨停（收盘或触及），或今日盘中最高价触及涨停价

### 否决5：游资出逃
龙虎榜净卖出 > 3000万

## 逐维度评分规则

### 1. 大盘整体情绪（30分）

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 涨停溢价 | 涨停股平均溢价 ≥ 1.5% | +10 |
| 涨停折价 | < 0% | -10 |
| 结构健康 | 涨停>35家 且 跌停<5家 | +8 |
| 涨跌比差 | 涨停/跌停 < 0.8 | -8 |
| 炸板受控 | 炸板率 < 30% | +7 |
| 炸板失控 | 炸板率 > 40%（<45%未触发否决） | -7 |
| 连板高度 | 最高 ≥ 4板 | +5 |
| 连板低迷 | 最高 < 3板 | -5 |

截断：[0, 30]

### 2. 主线题材情绪（30分）

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 题材第1名 | 概念热度排名第1 | +10 |
| 题材2-3名 | 排名2-3 | +5 |
| 题材4-5名 | 排名4-5 | +2 |
| 发酵增强 | 涨停数>前日 | +8 |
| 发酵持平 | 涨停数=前日 | +5 |
| 发酵减弱 | 涨停数<前日 | +3 |
| 发酵基础 | 涨停≥3只(无前日对照) | +6 |
| 资金共识强 | 涨停 ≥ 5只 | +7 |
| 资金共识中 | 涨停 ≥ 3只 | +3 |
| 退潮 | 涨停<3 + 最高连板<3 | -10 |
| 发酵/高潮 | 非退潮非分歧 | +5 |
| 分歧 | 炸板率>40% | 0 |

截断：[0, 30]

### 3. 板块梯队情绪（20分）

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 板块强联动 | 板块涨停 ≥ 5只 | +10 |
| 板块有热点 | 板块涨停 ≥ 3只 | +6 |
| 梯队完整 | 存在≥2只3板以上 | +4 |

截断：[0, 20]

### 4. 个股人气资金情绪（10分）

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 换手适中 | 5%-15% | +1 |
| 换手活跃 | 15%-25% | +2 |
| 换手偏高 | 25%-30% | +1 |
| 换手过热 | >30% | -2 |
| 20日涨停≥2次 | 近20日涨停≥2次 | +3 |
| 20日涨停1次 |  | +1 |
| 龙虎榜净率 | 游资净买入>0 (net_rate>0) | +2 |
| 连板基因 | 近60日曾≥2连板 | +3 |

截断：[0, 10]

### 5. 集合竞价情绪动能（15分）

数据源：Tushare stk_auction + daily（昨日成交量）。

**OpenGap 开盘跳空 × 市场状态乘数**：

| 跳空幅度 | 基础分 |
|------|:--:|
| 5%-8% | +5 |
| 3%-5% | +3 |
| 1%-3% | +1 |
| -1%~1% | 0 |
| -3%~-1% | -2 |
| <-3% | -4 |
| ≥8% + 秒板信号 | +5 |

市场乘数：牛市×1.3，震荡×1.0，熊市×0.6（扣分时熊市×1.5，最大1.5倍）

截断：[0, 5]

**CallVolRatio 竞价关注度**（竞价量/昨日成交量）：

| 量比 | 分值 |
|------|:--:|
| ≥ 3.0 | +5 |
| ≥ 1.5 | +3 |
| ≥ 0.5 | +1 |

**量比验证**：

| 条件 | 分值 |
|------|:--:|
| 竞价量比 > 5 | +3 |
| 竞价量比 > 3 | +1 |

**竞价成交额**：

| 条件 | 分值 |
|------|:--:|
| ≥ 500万 | +2 |
| ≥ 100万 | +1 |

### 高位情绪折扣

个股连板高度 ≥ 5板时：
- 5-6板：总分 × 0.85
- ≥7板：总分 × 0.70
