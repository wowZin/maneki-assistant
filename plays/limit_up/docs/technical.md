# 技术面评分

## 策略定位

专注A股T+1~T+3周期涨停潜力预判的纯技术面分析。六维度量化评分，含一票否决规则（动态阈值）、板块弱势天花板、时间因子。

数据源：Tushare stk_factor_pro（T-1）+ 同花顺实时量比。盘中优先使用同花顺实时量比覆盖（从 fund_cache 获取），替代 T-1 vol_ratio。

## 六维度权重

| 维度 | 权重 | 核心逻辑 |
|------|:--:|------|
| 量能结构 | 35分 | 放量启动、洗盘起爆、换手健康 |
| 趋势均线 | 25分 | 多头排列、回踩企稳、MA60方向 |
| 筹码结构 | 15分 | 换手衰减、布林带收敛 |
| 关键位置 | 12分 | 平台突破、下影支撑、上影假突破 |
| 资金动能 | 8分 | 价>中轨+量比确认、分时强势 |
| 板块协同 | 5分 | 行业共振、弱势天花板 |

## 一票否决规则

触发任一直接返回 0 分：

### 1. 放量破位
收盘 < MA20，且量比 > 近80日Top20% 或 量比 > 1.5

### 2. 高位滞涨
近20日涨幅>60%，换手率>近80日Top5% 或 换手>25%，收长上影（上影/实体>1.5）

### 3. 高位筹码发散
近3日换手逐日递增，且累计涨幅<2%

### 4. 持续缩量阴跌
连续3日量比<近80日Bottom10%（且绝对值<0.6），累计跌幅>3%

### 5. 资金持续出逃
近2日资金动能为负，且收盘/布林中轨<0.99

## 逐维度评分规则

### 1. 量能结构（35分）

### 6. 板块协同过滤（5分）

同行业个股MA20站上比例：使用模块级缓存 `_INDUSTRY_MA20_CACHE`，单次扫描中同行业多个候选股复用缓存，避免重复API调用。通过 stk_factor_pro 获取 peers 的 close 和 ma_bfq_20。

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 板块共振 | 同行业≥40%个股收盘>MA20 | +5 |
| 板块中性 | 同行业20%-40%个股>MA20 | +2 |
| 板块弱势天花板 | 同行业<20%个股>MA20 → 总分上限74 | 硬限制 |

截断：[0, 5]

## 时间因子

- 早盘冲动抑制（占位）：10:30前触发，预设标记，需14:00后验证回落。当前实现为 pass 占位。
- 尾盘确认加分：14:30后量比>Top20%或>1.5 → +3

## 板块弱势硬性天花板

同行业<20%个股站上MA20 → 总分上限74分

## 潜力等级

| 等级 | 阈值 |
|------|:--:|
| 高 | ≥75 |
| 中 | 55-74 |
| 低 | 35-54 |
| 无 | <35 或触发否决 |

# V3 技术面评分 (当前版本)

## 策略定位

数据驱动的重构版本。基于 400 样本 16 涨停的回测发现，V1/V2 技术面 Cohen's d = -0.10（负向区分力），说明原有启发式规则和否决触发有害。V3 从数据出发重构。

关键发现（来自 zt_pattern.py）：
- t_vol_ratio (-0.50): 高量比 STRONGLY NEGATIVE — 已放量的股次日更难涨停
- t_circ_mv_log (+0.47): 小市值 STRONGLY POSITIVE — 小盘弹性是核心条件
- t_upper_shadow_ratio (-0.19): 上影线 = 卖压信号
- t_5d_pct_sum (+0.17): 5 日动量正向

## V3 vs V1/V2 核心差异

| 维度 | V1/V2 | V3 |
|------|-------|-----|
| 量比评分 | 奖励高量比 (>Top20%) | 奖励适中量比 (1.0-2.5), d>3.0 不加分 |
| 否决规则 | 5 条 | 2 条 (放量破位 + 高位滞涨) |
| 板块协同 | 5 分, 多 API 调用 | 移除 (信号噪声) |
| 市值因子 | 无 | 新增 0-10 分加成 |
| 上影处理 | 仅在暴量滞涨触发 | 独立惩罚因子 (-5 ~ -8) |
| 趋势均线 | MA5/10/20 多头排列 + MA60 方向 | 仅 MA20 斜率 + close>MA20 |
| 5 日趋势 | 无 | 5 日累计涨幅 + 5 日阳线计数 |
| 资金动能 | 收盘 vs BOLL 中轨 + 量比 | 移除 (与 fundflow 维度重叠) |

## 移除的因子（V3 不再使用）

- 板块协同（概念共振/弱势天花板） — 大量 API 调用但信号噪声
- MA5/MA10/MA60 均线及多头排列 — 次日预测区分力弱
- 资金动能（收盘 vs BOLL 中轨） — 与 fundflow 维度重复
- 持续缩量阴跌否决、高位筹码发散否决、资金持续出逃否决 — 误杀率高
- 时间因子（早盘/尾盘） — 边际收益低
