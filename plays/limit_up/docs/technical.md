# 技术面评分

## 策略定位

专注A股T+1~T+3周期涨停潜力预判的纯技术面分析。六维度量化评分，含一票否决规则（动态阈值）、板块弱势天花板、时间因子。

数据源：Tushare stk_factor_pro（T-1）+ 东财实时量比。盘中优先使用东财实时量比覆盖（从 fund_cache 获取），替代 T-1 vol_ratio。

## 六维度权重

| 维度 | 权重 | 核心逻辑 |
|------|:--:|------|
| 量能结构 | 35分 | 放量启动、洗盘起爆、换手健康 |
| 趋势均线 | 25分 | 多头排列、回踩企稳、MA60方向 |
| 筹码结构 | 15分 | 换手衰减、布林带收敛 |
| 关键位置 | 12分 | 平台突破、下影支撑、上影假突破 |
| 资金动能 | 8分 | 价>中轨+量比确认、分时强势 |
| 板块协同 | 5分 | 行业共振、弱势天花板 |

## 一票否决规则

触发任一直接返回 0 分：

### 1. 放量破位
收盘 < MA20，且量比 > 近80日Top20% 或 量比 > 1.5

### 2. 高位滞涨
近20日涨幅>60%，换手率>近80日Top5% 或 换手>25%，收长上影（上影/实体>1.5）

### 3. 高位筹码发散
近3日换手逐日递增，且累计涨幅<2%

### 4. 持续缩量阴跌
连续3日量比<近80日Bottom10%（且绝对值<0.6），累计跌幅>3%

### 5. 资金持续出逃
近2日资金动能为负，且收盘/布林中轨<0.99

## 逐维度评分规则

### 1. 量能结构（35分）

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 放量启动 | 量比>Top20%或>1.5，且当日量>3日均量1.3倍 | +20 |
| 量能偏强 | 仅满足放量或量增其一 | +10 |
| 洗盘起爆 | 前5日中≥2日量比<Bottom30% 或 <0.8，当日量比>中位数 或 >1.2 | +10 |
| 换手健康 | 换手∈[20%分位,80%分位]，动态区间 min(tr_20pct, 3.0) ~ max(tr_80pct, 15.0) | +5 |
| 换手无量 | 换手<Bottom10%或<1.5% | -5 |
| 暴量滞涨 | 换手>Top5%或>15%，上影/实体>1.0 | -10 |

截断：[0, 35]

### 2. 趋势均线（25分）

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 多头排列 | MA5>MA10>MA20 且 MA20斜率>0 | +15 |
| 均线多头(斜率平) | MA5>MA10>MA20 但 MA20斜率不增 | +10 |
| 空头排列 | MA5<MA10 且收盘<MA20 | -10 |
| MA60下倾 | MA60 < 5日前MA60 | -5 |
| 回踩MA10企稳 | 近5日最低触及MA10×1.01 且收盘>MA10 | +5 |
| 回踩MA20企稳 | 近5日最低触及MA20×1.01 且收盘>MA20 | +3 |
| 缩量回踩 | 昨日量比<中位数，回踩MA10 | +5 |
| 收盘≤MA20 | 硬标准扣分 | -5 |

截断：[0, 25]

### 3. 关键位置形态（12分）

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 平台突破 | 近10日振幅<15%，布林带宽<15%，收盘接近平台高点(×0.99)，量比>中位数或>1.0 | +8 |
| 下影支撑 | 下影线/实体>0.3 | +4 |
| 假突破 | 近3日≥2日上影/实体>1.0 | -4 |

截断：[0, 12]

### 4. 筹码结构（15分）

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 换手递减锁定 | 近5日换手非增序（>=），最新<5日均值 | +10 |
| 换手趋降 | 近3-4日换手降低趋势 | +5 |
| 波动收敛 | 布林带宽 ≤ 近20日Bottom30% | +5 |
| 换手递增滞涨 | 近3日换手递增+累计涨幅<3% | -10 |

截断：[0, 15]

### 5. 日内资金动能（8分）

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 资金正向 | 收盘/中轨>1.01 且 量比>中位数 | +5 |
| 价>中轨 | 收盘/中轨>1.01 | +2 |
| 分时强势 | 收盘/中轨>1.01 且 日内回撤<1.5% | +3 |
| 分时走弱 | 收盘/中轨<0.99 | -8 |

截断：[0, 8]

### 6. 板块协同过滤（5分）

同行业个股MA20站上比例：使用模块级缓存 `_INDUSTRY_MA20_CACHE`，单次扫描中同行业多个候选股复用缓存，避免重复API调用。通过 stk_factor_pro 获取 peers 的 close 和 ma_bfq_20。

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 板块共振 | 同行业≥40%个股收盘>MA20 | +5 |
| 板块中性 | 同行业20%-40%个股>MA20 | +2 |
| 板块弱势天花板 | 同行业<20%个股>MA20 → 总分上限74 | 硬限制 |

截断：[0, 5]

## 时间因子

- 早盘冲动抑制（占位）：10:30前触发，预设标记，需14:00后验证回落。当前实现为 pass 占位。
- 尾盘确认加分：14:30后量比>Top20%或>1.5 → +3

## 板块弱势硬性天花板

同行业<20%个股站上MA20 → 总分上限74分

## 潜力等级

| 等级 | 阈值 |
|------|:--:|
| 高 | ≥75 |
| 中 | 55-74 |
| 低 | 35-54 |
| 无 | <35 或触发否决 |
