# 资金面评分

> **2026-07-02 重构后**：资金面维度使用 `fundflow_rebuilt` 作为默认打分。具体因子见 [`factors.md`](./factors.md#维度fundflow)。资金面不入 `total_score`，仅作为观察指标输出。



## 策略定位

专注A股T+1~T+3资金驱动型涨停预判。五维度量化评分，含一票否决规则（市场状态调节器、一字板豁免、3日累计豁免）。

数据源：同花顺 f62 实时主力净流入（优先）+ Tushare moneyflow（T+1降级）+ l2api Level2（盘口买卖比/VWAP）。

## 五维度权重

| 维度 | 权重 | 核心逻辑 |
|------|:--:|------|
| 超大单主力净流入 | 35分 | 规模阈值、占比健康、持续抢筹、散户接盘过滤 |
| 龙虎榜机构游资 | 25分 | 盘后龙虎榜（机构+游资净买）/ 盘中封板质量因子 |
| 分时盘口资金抢筹 | 20分 | l2api盘口买卖比、VWAP乖离率 / 日频代理 |
| 融资与聪明资金 | 7分 | 融资余额增速 / 北向持股变动 |
| 筹码抛压与锁仓 | 13分 | 净流入递增、无抛压、流入加速 |

## 一票否决规则

触发任一直接返回 0 分：

### 否决1：主力持续流出
近3日主力累计净流出 > 0.5%流通市值

### 否决4：纯散户博弈
主力净占比 <5% 且 3日累计净流入 ≤ 0

**豁免条件**：
- 一字板（涨停且开板次数=0）→ 直接豁免
- 3日累计净流入>0 → 不否决，转入维度1占比因子扣-5分

### 否决2：龙虎榜大额撤离
机构/游资净卖出 > 净买入2倍（且 >1000万）

### 否决3：分时资金背离
当日涨幅>3% 且 主力净流出，且 不满足豁免条件

**豁免条件**：收盘/最高>0.92 且（换手<15% 或 3日净流入>0）

**市场状态调节器**：低迷市（全市场成交<8000亿或跌停>20家）→ 相关系数阈值放宽至 -0.75

### 否决5：尾盘集中兑现
不否决，仅扣分并入维度3。

- l2api分钟K线可用：
  - 14:30后成交量占比>25%且尾盘均价<VWAP → 扣8分
  - 尾盘松动：尾盘成交量占比>35%且均价<全天VWAP×0.995 → 扣5分
- 日频代理降级：
  - 净流出+收盘低于均价线 → 扣5分
  - 收跌+净流出+低于均价 → 再扣5分

## 逐维度评分规则

### 1. 超大单主力净流入（35分）

**规模阈值（实时优先）**：

| 数据源 | 条件 | 分值 |
|------|------|:--:|
| 同花顺f62(实时) | 净流入/成交额 ≥ 3% | +25 |
| 同花顺f62(实时) | 净流入/成交额 < 0.1% | -15 |
| Tushare(T+1) | 净流入/流通市值 ≥ 0.3% | +15 |
| Tushare(T+1) | 净流入/流通市值 < 0.1% | -15 |

**占比健康**：

| 条件 | 分值 |
|------|:--:|
| 主力净占比 > 30% | +10 |
| 主力净占比 5%-15% | -5 |
| 否决4豁免转入 | -5 |

**持续抢筹**：近3日连续净流入 → +10

**散户接盘过滤**（两者同时满足才扣分）：
- 主力净额 < 0（主力在卖出）
- 总净流入 > 0（散户接盘使总净流入为正）

**豁免**（满足任一即不扣分）：
- 当日涨停且换手率在 5%-25% 区间（换手板属健康博弈）
- 近3日主力累计净流入 > 0（主力前期已进场）

得分：-20

截断：[0, 35]

### 2. 龙虎榜机构游资（25分）

**盘中方案**（Tushare limit_list T-1日封板质量）：

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 封单强度 | 封单金额/流通市值 ≥ 1% | +10 |
| 封单弱 | < 0.3% | -10 |
| 早封板 | 首次涨停 < 10:30 | +8 |
| 尾板 | > 14:00 | -8 |
| 秒封/一字板 | 开板次数=0 | +7 |
| 开板1次 |  | +3 |
| 开板≥3次 |  | -7 |
| 首板豁免 | T-1非涨停但T日涨幅>7% | 0分 |
| 未涨停 | T-1非涨停且T日涨幅≤7% | -15 |

**盘后方案**（Tushare top_list/top_inst）：

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 资金合力 | 机构+游资净买入 > 3000万 | +12 |
| 席位主导 | 单一席位净买入占比 > 40% | +8 |
| 龙虎榜净买 | 净买率 > 0 | +5 |

截断：[0, 25]

### 3. 分时盘口资金抢筹（20分）

**l2api实时因子（优先）**：

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 盘口买压 | 总买量/总卖量 > 1.5 | +8 |
| 盘口偏买 | > 1.2 | +5 |
| 盘口偏卖 | < 0.7 | -5 |
| VWAP上方 | 价格/VWAP偏离∈(0, 1%) | +6 |
| VWAP附近 | 偏离∈(-0.5%, 0] | +4 |
| VWAP下方 | 偏离 < -2% | -5 |

**日频代理（l2api不可用时）**：

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 持续净流入 | 净流入>0 且 最低价≥昨收×0.99 且 收盘/最高>0.95 | +10 |
| 强承接 | 换手>3% 且 换手/振幅>2.0 | +6 |
| 超大单主导 | 超大单净流入>0 且 散户反向 | +4 |
| 拉升无量 | 涨幅>5% 换手<2% 非涨停 | -12 |
| 放量出逃 | 跌幅>3% 换手>8% | -12 |
| 对倒嫌疑 | 主力净流出 换手>10% | -12 |

**尾盘走弱扣分**：l2api精确检测或日频代理，扣5-8分

截断：[0, 20]

### 4. 融资与聪明资金（7分）

**盘中方案**（Tushare margin_detail T-1）：

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 融资5日连增 | 融资余额连续5日增长 | +3 |
| 融资活跃 | 融资买入额 / (融资买入额 + abs(总净流入)) > 8% | +2 |
| 融资主力同向 | 融资增速与主力净流入同向 | +2 |
| 融资3日连降 | 融资余额连续3日下降 | -5 |

**盘后方案**（Tushare hk_hold 北向）：

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 北向5日增持 | 持仓量5日增长 | +6 |
| 持股占比增加 | Δ比例 > 0.05（即5%，硬阈值，非百分比点） | +4 |
| 北向持股>0 | 当日持仓>0 | +4 |

截断：[0, 7]

### 5. 筹码抛压与锁仓（13分）

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 流入递增锁仓 | 近3日净流入递增（前天≤昨天≤今天）且今天>0 | +7 |
| 无抛压 | 近3日净流入均≥0 | +3 |
| 流入加速 | 今日净流入 > abs(前2日均值) × 1.5（前2日取绝对值） | +3 |

截断：[0, 13]

## 边缘区间二次确认

53-56分时：维度1≥21 且 维度5≥8 → 升级为高潜力；否则维持中等

|------|:--:|
| 高 | ≥75 |
| 中 | 55-74 |
| 低 | 35-54 |
