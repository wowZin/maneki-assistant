# 首板预测因子设计

## 背景

现有 shortterm 因子主要奖励"连板潜力"（首板×15、二连板×30、四连板+50），
但 81% 的涨停是首板（285 只样本中 230 只）。对首板场景预测力很差。

## 目标

设计一个专门预测**首板涨停**的因子，回答"为什么这只股票今天会首次涨停"。

## 数据发现（285 只首板涨停股）

| 特征 | 占比 | 说明 |
|------|------|------|
| 分歧转一致 | 75% | 开盘分歧→资金涌入→封板 |
| 竞价高开/活跃 | 47% | 开盘价高于前收 + 竞价量放大 |
| 资金净流入 | 39% | 中单/主力净流入 |
| 概念板块热度 | ？ | 需进一步分析 |

## 因子结构

```
首板预测因子 (0-100)

├── 竞价异动 (30分)
│   ├── 高开幅度：开盘涨幅 > 2% 加分
│   ├── 竞价量比：竞价量 / 前日均量 > 2 加分
│   └── 竞价换手：竞价换手率 > 0.5% 加分
│
├── 分歧转一致 (30分)
│   ├── 开盘分歧：开盘涨幅 < 3% + 换手活跃 → 分歧信号
│   ├── 资金承接：开盘后中单/主力净流入（来自 shortterm 的共振分）
│   └── 封板潜力：量比 > 1.5 + 涨幅 > 7% → 一致性确认
│
├── 资金抢筹 (20分)
│   ├── 中单净流入 > 0（从 fundflow 取）
│   └── 主力净流入 > 0（从 fundflow 取）
│
└── 板块共振 (20分)
    ├── 所属概念今日有涨停股（来自 sentiment 的概念热度）
    └── 所属概念涨幅中位数 > 0
```

数据来源全部复用现有数据（Tushare daily/daily_basic/moneyflow、同花顺概念缓存），不新增 API 调用。
