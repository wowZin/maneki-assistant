# 基本面评分

## 策略定位

专注A股涨停潜力预判的基本面分析。五维度量化评分，含财务避雷一票否决（行业豁免）、见光死惩罚、非线性共振加分、困境反转加分。

数据源：Tushare（T+1）。

## 五维度权重

| 维度 | 权重 | 核心因子 |
|------|:--:|------|
| 盈利业绩 | 40% | ROE、扣非净利润同比、营收增速 |
| 题材事件 | 30% | 概念数量、近期公告数、见光死衰减 |
| 股东筹码 | 15% | 股东户数变化、连板基因、解禁冲击 |
| 财务健康 | 10% | 负债率、流动比率（扣分项） |
| 估值性价比 | 5% | PEG、困境反转加分（仅加分项） |

## 一票否决规则

触发任一即返回 0 分，不进入评分：

### 商誉占比 > 30%
- 行业豁免：医药/医疗/电子/半导体/元器件行业 ROE>10% 免于否决
- 豁免时记录风险但不否决

### 资产负债率 > 70% 且经营现金流连续为负
- 行业豁免：房地产/建筑/非银金融/公用事业/银行/综合行业仅看现金流
- 豁免行业：负债率高不否决，仅当现金流连续为负才否决

### 扣非净利润连续亏损（同比下降超 50%，dt_netprofit_yoy < -50）
- 困境反转豁免：最新净利润>0 且 扣非净利润>0 且 去年同期扣非净利润<0 → 免于否决
- 无困境反转时才否决

### 非经常性损益占比 > 50%
- 计算：abs(净利润 - 扣非净利润) / 净利润

### 近6个月存在 > 流通盘10% 的大额解禁

### 主业营收占比（已废弃）
- Tushare income 表 revenue ≈ total_revenue，恒≈100%，无区分能力

## 逐维度评分规则

### 1. 盈利业绩（40%）

基准分 0.5，各因子加减：

| 因子 | 条件 | 分值 |
|------|------|:--:|
| ROE | >15% | +0.20 |
| ROE | >10% | +0.10 |
| ROE | <5% | -0.15 |
| 扣非净利润同比 | >50% | +0.25 |
| 扣非净利润同比 | >20% | +0.15 |
| 扣非净利润同比 | <0% | -0.20 |
| 营收同比增速 | >30% | +0.15 |
| 营收同比增速 | <0% | -0.10 |

截断：[0, 1]

### 2. 题材事件（30%）

基准分 0.5：

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 概念数量 | ≥8个 | +0.20 |
| 概念数量 | ≥4个 | +0.10 |
| 概念数量 | 0个 | -0.10 |
| 近10日公告 | ≥3条 | +0.20 |
| 近10日公告 | ≥1条 | +0.10 |

**见光死惩罚**：公告前涨幅过大时事件因子衰减

```
Price-in_Ratio = 近20日涨幅 / (|eps上调幅度| + 5)
```

- PIR > 2.5 且 (业绩>0.6 或 事件>0.7) → 事件因子 × 0.5
- PIR > 3.5 → 业绩因子 × 0.7

截断：[0, 1]

### 3. 股东筹码（15%）

基准分 0.5：

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 股东户数环比下降 | ≥5% | +0.20 |
| 股东户数环比增加 | >5% | -0.20 |
| 近60日连板基因 | ≥2连板 | +0.15 |
| 未来30日解禁冲击 | 无>2%流通盘解禁 | +0.10 |

截断：[0, 1]

### 4. 财务健康（10%）

满分 1.0，仅扣分：

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 负债率 | >60% | -0.20 |
| 负债率 | >50% | -0.10 |
| 流动比率 | <1 | -0.20 |

截断：[0, 1]

### 5. 估值性价比（5%）

无基准分，仅加分：

| 因子 | 条件 | 分值 |
|------|------|:--:|
| 远期 PEG | PE/ROE < 1.5 | +0.30 |
| 困境反转 | 最新净利润>0 且扣非>0 且去年同期扣非<0 | +0.30 |

截断：[0, 1]

## 综合评分

```
Base_Score = 40×F_业绩 + 30×F_事件 + 15×F_筹码 + 10×F_财务 + 5×F_估值
```

### 非线性共振加分

- 条件A：业绩≥0.8 且 事件≥0.7 且 近10日有公告 → +15
- 条件B：筹码≥0.8 且 估值≥0.6 → +10
- 取最高，不叠加

### 困境反转独立加分

- 最新单季净利润>0 且扣非>0 且 去年同期扣非<0 → +5

### 最终得分

```
Final = min(100, Base_Score + Resonance_Bonus + Turnaround_Bonus)
```
