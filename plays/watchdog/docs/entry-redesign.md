# 买入策略重设计：跟主力，不追价格

> 状态：设计提案，待审核 → 回测验证 → 再替换 confirm.py
> 依据：08-12（confirm.py 上线）以来生产交割单 + L2 逐笔主力大单字段

## 一、现状诊断（生产交割单实测）

| 指标 | 数值 |
|---|---|
| 卖出笔数 | 174 |
| 胜率 | 24.1%（42 胜 / 126 负 / 6 平） |
| 总盈亏 | -3716 元 |
| 平均盈利 / 平均亏损 | +106 / -65 元 |
| 盈亏比 | 1.64 |
| 盈亏平衡胜率 | 37.9% |

结论：
- 离场框架「赚大亏小」（盈亏比 1.64）有效，不是主要矛盾。
- 死穴是入场胜率 24.1%，比盈亏平衡低 13.8pt。
- `trend_up_trigger` 要求「当前价 ≥ 前 10 轮新高 + 放量」，本质是**买在短期局部顶**——价格创新高是结果不是原因，等创新高再买已经晚了。

## 二、为什么「追价格」必然低胜率

1. 创新高买入 = 买在主力派发区：主力拉高 → 散户追高 → 主力出货。
2. A股放量 ≠ 吸筹，打板语境下常是「出货 / 对倒」（拉高吸引跟风盘）。
3. T+1 强制隔夜：盘中追买，次日开盘吃跳空。实测早盘（≤09:45）亏损 74 笔 -3966 元，是总亏损的主体。

## 三、新核心原则：主力大单资金流是领先信号

L2 逐笔（AbLv2）已订阅，ws_daemon 每 60s 落盘大单统计：

- `big_net_amount` = 大单主动买 − 大单主动卖（大单 ≥20 万）
- `super_net_amount` = 超大单主动买 − 超大单主动卖（超大单 ≥100 万）
- 方向判定：成交价 vs 盘口（b1p/s1p）——主动吃掉卖一 = 真买

主力吸筹先于价格拉升，主力派发先于价格下跌。入场依据从「价格涨了」改为「主力在买」。

## 四、新买入确认器 `fund_accumulate_confirm`（替代 trend_up_trigger）

每轮 60s 评估。输入：ws_snap 的 `big_net_amount` / `super_net_amount` / `last` / `vwap` / 盘口 / 分时。注意 ws_snap 中这些值是字符串，实现需 `float()`。

触发条件（全部满足）：

1. **主力持续净流入（吸筹，非单笔脉冲）**
   - 近 N 轮（默认 5）内 `super_net + big_net` 累计 > 0
   - 且近 N 轮中 ≥ K 轮（默认 3）单轮净额 > 0

2. **未过度拉升（不追顶）**
   - 现价 ≤ 当日最高 × 0.98
   - 且当日涨幅 ≤ 5%

3. **主动买占优（方向确认）**
   - `big_buy_amount > big_sell_amount`

4. **选股闸（候选质量，沿用现有 surge 主闸）**
   - `model_score ≥ 20`（surge_scanner 已筛）
   - 涨停基因：近 20 日涨停 ≥1 次（可选加强，待回测定）

防诱多拒绝（任一命中不买）：
- 主力净流入但价格放量下跌（量比 >1.5 且跌幅 >1%）→ 出货/对倒
- 超大单单笔占比过高（单笔 super > 近 N 轮累计净额 50%）→ 对倒嫌疑

## 五、出场框架（先保留，待入场修复后重标定）

- 保留：高位出场（隔夜低开开盘卖）+ 固定止损 -4%（尾部兜底）
- 回撤 2%：当前天天触发是**坏入场的果**，不是因。入场修复后重标定阈值。
- 新增（二期，可选）：主力出货离场——`big_net` 连续 3 轮转负 → 卖，与入场逻辑对称。

## 六、两条独立的亏损杠杆（必须分开看）

1. **入场杠杆**（本设计解决）：追创新高 → 跟主力吸筹，提胜率。
2. **隔夜跳空杠杆**（T+1 结构性，独立于入场质量）：
   - 盘中买 T+1 必吃隔夜跳空，即使入场 100% 对也会被跳空吃掉一部分。
   - 缓解：高位出场（已有）+ 或改尾盘买 + 或转 T+0 标的（转债，事后 93.7% 胜率方向）。
